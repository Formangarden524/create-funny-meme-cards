# 使用者品牌与项目出处

品牌工坊位于`../assets/poster-studio/index.html`，离线运行，支持样张或上传成图的昵称、签名、二维码合成与PNG导出。个人资料只保存在当前页面内存，不自动上传或写入资料包；下载配置是可选操作。当前支持下载配置，尚无配置导入或跨设备同步。

## 昵称辅助

知道昵称：直接填写，最多16字。没有昵称：按兴趣、角色和语气给出3—5个候选，点击采用。页面提供本地关键词组合灵感；AI宿主可按用户描述另起昵称，不冒充已查重或已注册。品牌素材可选，无配置仍可完成无个人品牌创作。

## 二维码辅助

1. 微信个人码等现成码：由用户上传清晰、裁切完整、留有白边的PNG/JPEG/WebP原码。不能仅凭昵称、手机号或微信号推导添加好友码。
2. 已有主页/联系网址：输入明确的http/https目标，在本地生成二维码，不打开或上传目标网址。没有网址时说明还缺跳转目标，先完成无二维码海报，不虚构可扫码身份。
3. 图片生成后单独合成黑白码，四周留白、等比例缩放、不裁切、不覆盖模块。上传原码先本地解码；导出前从最终合成区域再解码，与原内容逐字比较。无法解码或不一致时阻止带码导出，用户可重新提供清晰原码或选择不添加。
4. 解码一致只证明像素中的内容一致，不能证明目标有效、平台识别正常或二维码长期有效。交付时请用户用手机试扫确认。

`assets/brand.example.json`是公开示例；个人微信码不随包分发，也不从参考图自动提取。默认昵称为空时不替用户假定名字。私人成图、二维码与配置应放忽略目录。
