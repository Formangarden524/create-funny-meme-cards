# 使用历史与复用约定（后续实现）

本阶段只定义数据契约。没有catalog脚本、数据库或同步服务，不能声称记忆功能已经实现。

公共年代知识包只读；使用者配置、实际作品和个人反馈存在其自选可写目录。data_dir使用绝对路径；相对品牌素材路径以配置文件所在目录解析。升级不覆盖个人数据，不自动提交Git。

默认在工具与权限可用时归档；用户说不记录则不保存。此默认行为须待实际实现与验证。没有数据目录时先说明本次排重局限；查重范围仅限成功读取的历史。

| 指令 | 约定 |
|---|---|
| 新的/再来一批 | 排除历史同句和近义改写；相同模板要说明 |
| 完全全新的，不要旧套路 | 进一步排除已用模板家族；不足时如实报告 |
| 经典可以复用 | 允许重复，标记原ID与上次使用记录 |
| 旧梗换场景 | 新建变体并保留parent_id |
| 改上次那组 | 追加作品版本，不覆盖原图和原提示词 |

历史的所有版本参与精确查重。语义与模板比较保留判断依据；不把“反差”“夸张”等宽泛机制全部排除。全球原创性不是本地排重可以证明的。

事件关系：entry_id → variant_id → output_id → feedback。模型自拟文案可有parent_id=null；使用公共条目改编则有父ID。作品中保存实际提示词、产物引用和检查状态。反馈状态为not_reviewed/requested_changes/accepted/rejected，只按明确反馈更新。

实现时应校验字段、ID引用、版本及文件存在性，采用防并发丢写与原子提交。schemas/runtime-event.schema.json是事件外形草案；kind对应payload字段和引用完整性仍须由第3步验证器实现。
