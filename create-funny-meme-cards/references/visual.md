# 漫画与版式

默认白底、炭黑字与线条、松绿#35685B强调，可爱圆团人物和清晰中文。数量、配色、横竖版、单卡或合集随请求调整。

每条提供完整文案、场景与一幅有动作反差的小漫画。角色要表现笑点，不用通用办公图标替代情境。10条过密时拆页；避免截断包袱或缩成无法阅读的小字。

生图提示词包含：主题、画幅、实际条数、逐字文案、每项人物动作与反差、分组方式、品牌留白和内容性质。不得继续固定为两列十条。

不随包提供第三方表情包图片、角色原照、音乐或视频。来源中的视觉机制可以研究，具体素材能否复用需另查。

成图候选需核查错字、顺序、完整性、清晰度和动作效果。保存实际发送的提示词，不以模板代替日志。二维码与品牌合成见branding.md；已有三风格样张与本地合成工坊，具体检查结果以本轮记录为准。

## 初期三风格

反转漫画（comic）：白底黑线、动作反差；萌宠吐槽（pets）：猫狗神态、打工日常；复古表情包（retro）：米白黑红、原创荒诞角色和大字包袱。定义见`../assets/poster-studio/styles.json`，执行见[image-generation.md](image-generation.md)。

## 信息图合集

用户要合集时，采用collection：标题区＋编号分格正文＋底部说明；默认8条、两列四行。每条短句配对应小漫画，不做纯文字清单或知识科普。2—4条可单列，5—10条双列；超过10条拆页。昵称、原二维码和项目出处在成图后独立追加。
