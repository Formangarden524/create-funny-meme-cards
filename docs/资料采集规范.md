# 年代资料采集与入库标准

## 资料分层

- 历史背景：网络发展节点，不计入热梗条数。
- 来源核对条目：已有实际读取的来源，明确来源证明什么；此前139条归于来源核对层，但来源核对不等于符合当前趣味收录标准。
- 待核线索：只有搜索摘要、原件读取失败或日期仍需核实的对象，独立存backlog，不计入已核对条目。
- 实时趋势：必须另有本次窗口内的证据或指标快照。本包尚无此类热度数据。

source_checked只表示来源已读，不能解释为首创核实、权利清理、当前热度或用户认可全部完成。

## 收集范围

包含流行语、句式模板、视觉梗、动画趋势、网络表达、早期网络幽默；不是每个词都是现成笑话。中文优先，英文仅补充在大陆有实际传播证据的表达。海外原始资料保留供复审，不与主库并列。

1960年代仅列网络前史；1970/1980年代不硬凑大众热榜。1990年代中文论坛材料目前仍有缺口，斑竹、灌水、886在待核线索中。

## 核查流程

1. 找到原帖、原视频、平台趋势栏目、同期新闻、机构/组织者发布；二手资料也可收录，但标明类别。
2. 读取正文与上下文，登记来源标题、URL、阅读方式、发布日期及采集日期。转载网站日期不替换原事件年份。
3. 为每条写supports：来源具体支持词义、年度入选、传播节点中的哪一项。不要把整页所有说法自动视为证实。
4. 分开记录原作品、可见网络事件、走红/复兴时间；未知留null。reference_year仅供分组，grouping_reason必须解释依据。
5. 释义写简短转述，不复制长段文章。漫画机制、场景和构思存editorial，明确是编辑解读。
6. 不收集私人聊天或账号凭证，不分发未经确认可再分发的原图、音乐或视频。公开网页可访问不等于媒体已获开源许可。
7. 写入知识文件后更新轻量索引，检查ID与来源引用。不要把历史收藏写入个人“已使用”记录。

## 热度证据

保存观察对象、平台、原始指标、单位、地域、窗口和采集时间。未知数据留null；没有第二个可比快照不计算增长。平台官方编辑推荐、年度评选、单个视频累计播放分别标记，不强行做全网总榜。
