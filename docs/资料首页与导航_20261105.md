# 资料首页与页面导航

依据用户确定的设计：应用首页直接展示好玩资料，原介绍首页改为项目说明；整个项目重视页面间导航。

- 根地址与新安装PWA启动页打开资料库。保留旧app.html路径；旧安装若仍使用该启动地址，在独立窗口中转入资料首页；项目说明使用app.html?view=about。
- 全局固定导航：资料首页、海报工坊、资料维护、项目说明，标明当前页面。顶部项目链接回资料首页。
- 资料首屏缩短介绍，保留近期倒序、关键词与分类筛选、三个已跟进表达入口和具体用法。窄屏折叠高级筛选，用户可展开；桌面保持展开。
- 条目“用这个做海报”携带公开条目ID；工坊载入当前主库文案与画面构思，并提供返回该条目的链接。预览仍明确为风格样张，不把带入文案视为已生图。
- 项目说明集中放安装、模块与离线能力边界；维护与创作均可返回资料首页。
- README展示真实网页截图与已有AI样张。截图不宣称为操作系统独立窗口截图，不包含个人二维码与私人笔记。

检查重点：根路由、新旧启动地址、离线根页面、导航目标与高亮、筛选响应式切换、资料→海报→原资料往返；资料排序与原笔记不因此改动。
