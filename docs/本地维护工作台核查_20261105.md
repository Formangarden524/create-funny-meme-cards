# 本地维护工作台核查

已实现本机HTTP工作台、公开RSS联网查询与新发现标记、Obsidian采集收件箱、待核线索保存、Markdown编辑、删除回收与恢复、编辑旧版本恢复。无云端数据库，原有笔记为主本。当前主库54条、复审85条，未为演示而修改或删除真实条目。

隔离副本4组回归通过：编辑与旧版恢复、错误格式回滚、过期版本拒绝覆盖；主库及复审区删除恢复（含示例引用的父条目）；联网结果已见去重、待核线索写入与失败记录；本机HTTP、写令牌、同源/Host校验与私人目录阻止访问。测试中的检索响应是固定测试数据，不算真实联网证据。

真实联网：首次Python urllib请求两个源超时，失败记录保留；改用本机curl请求后，Google News与Bing检索RSS均成功，实际返回合计15条去重链接。再次通过页面点击查询同一主题，返回15条、0条首次发现，验证已见标记与笔记持久化。来源原页未在此步骤逐条阅读，结果是文章线索，不是15个已核查新梗。未启用平台账户、实时热榜或自动周期采集。

浏览器验证主库54条、复审85条、空回收站、原始Markdown编辑器、真实查询按钮与存储记录；未上传整库或私人二维码。数据/本地链接、生成结果一致性、JavaScript语法与skill格式检查通过。当前服务仅本机可用，不作为公开站点后端。
