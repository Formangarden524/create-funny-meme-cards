# 三风格海报与品牌工坊

2026-11-05按用户要求扩展。使用[海报工坊](../create-funny-meme-cards/assets/poster-studio/index.html)。

| 风格 | 表现方式 | 适合内容 |
|---|---|---|
| 反转漫画 | 原创圆团人物、白底黑线、动作反差 | 聊天接话、熟人调侃、生活反转 |
| 萌宠吐槽 | 猫狗真实毛发、夸张神态、暖色 | 打工日常、内心戏、自嘲 |
| 复古表情包 | 黑红网点、米白纸色、原创荒诞角色 | 大字吐槽、荒诞颁奖、短句包袱 |

先选风格，再写标题、包袱和画面动作；导出生图任务交给支持生图的AI执行，或复制提示词到自己使用的模型；拿到成图后上传工坊。页面已有实际生图样张；修改文案不会自动改动样张，也没有在网页内直连任何模型API。

昵称可直接填写，也可用关键词辅助组合候选，未查重。二维码支持原码上传、已有网址本地生成、暂不添加三种方式。微信个人码须从微信保存后上传；没有目标网址时不能凭空生成账号二维码。二维码组件在本地生成/解码，不发送个人信息，导出前核对原内容与合成区域内容，失败时阻止带码导出。仍需手机试扫目标。

成图末尾单独追加品牌区，昵称/签名/二维码与项目出处独立。默认保留“工具源自：秋哥 · 夸损有梗”；作品上显示开关不替代未来许可证义务。当前不确定最终开放许可证，不把样张生成解释为已完成GitHub发布。

个人配置可下载，当前没有配置导入与持久化；重开页面需重新填写，个人下载文件请存入私人目录。公共包不含参考附件中的微信码。本轮只把AI新生成的无私人码样张加入公开预览。

二维码组件来自[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT）与[jsQR](https://github.com/cozmo/jsQR)（Apache-2.0）；原许可证随包保留，来源和文件摘要见工坊vendor目录的来源清单。

## 新增：信息图合集

[进入合集模式](../create-funny-meme-cards/assets/poster-studio/index.html?style=collection)。默认8条打工日常段子，竖版9:16、两列四行，每条有编号、完整短句和对应小漫画。可逐行修改为2—10条；超过10条拆页。原有三种单张风格保留。品牌区继续独立合成，二维码不交给生图模型绘制。

## 选中文案与风格切换

从资料卡片“用这个做海报”进入时，完整带入名称、用法与画面构思。风格只改变画面方向和提示词，不再替换成对应模板的文案。单张切到合集仍保留原内容，合集不足2条时提示补充，不自动填入其他示例。

当前文案在右侧以“尚未生图”草稿展示；风格样张需要明确点击“查看当前风格样张（仅参考）”，不会当作选中文案的成图。上传模型生成的图片后再合成昵称、二维码和导出PNG。导出的任务附带原条目ID与当前文案。

标题、文案、画面与风格保留在当前标签页的sessionStorage，刷新或通过本页导航返回时可继续编辑；这不是作品历史或Obsidian持久化。昵称、二维码与上传图片仍需在离开前导出。读取条目失败会留空并明确提示，不能静默退回样例。

回归：`node tools/test_studio_transfer.cjs`，覆盖完整带入、四风格切换、手动修改、导出任务、样张隔离、会话恢复、缺失条目及慢请求。
