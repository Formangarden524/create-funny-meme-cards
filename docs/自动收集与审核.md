# 自动收集与审核

目标是AI完成查找、整理和修订，人负责审核与意见。手动新增仍保留，作为补充入口。

## 怎么使用

1. 打开本地“资料维护”，点击“手动整理一批”。一般需几分钟，页面显示运行、完成或失败状态。
2. AI先处理已有修改意见，再找近7天中文趣味表达。排除已有名称、别名及已跳过候选；整理含义、用法、笑点、画面、来源与限制。
3. 在“审核收件箱”查看候选与来源。可直接改名称、含义、用法、画面和分寸，点击“通过，加入首页”；保存到Obsidian正式笔记并重建资料页。
4. 需要AI重写时填修改意见，点击“按意见重新修改”。系统保留已改文字与意见，尝试立即启动一轮修订；已有任务运行或暂时失败时，意见保留到下一轮手动或定时处理。修订后状态为“已按意见修订”，仍需人工通过。
5. 不合适的“先跳过”，不会被同名候选反复覆盖；可在“已跳过”范围中恢复。

生成草稿不会自动进入首页、发布作品或推送GitHub。审核草稿与生成作品历史是不同功能。

## 定时与手动

维护者本机已按用户要求，在Codex中设置每周日19:00（Asia/Shanghai）运行一批，默认最多新增5条；实际能找到多少取决于来源与去重。定时任务先检查是否已有运行中的任务，避免重复启动。仅有新候选、修订结果或需要处理的失败时通知。

手动按钮随时可用。它调用本机Codex CLI，以当前已登录账号运行，只读研究环境中使用联网搜索，返回结构化JSON；程序校验后写私人收件箱。模型不会直接写正式库。缺少CLI、登录、网络或有效结果时显示真实失败。

下载此仓库不等于安装维护者的定时任务。新使用者需自行安装并登录Codex、在AI宿主配置周期任务。手动运行需要本地维护服务；Codex定时任务需要电脑和Codex应用保持可运行，本机离线或休眠时不承诺准点执行。模型使用受账号额度与服务可用性限制。

定时任务可执行以下项目相对命令，不需要向网页填写模型密钥：

```bash
.venv/bin/python tools/auto_collect.py --status
.venv/bin/python tools/auto_collect.py --limit 5
```

## 本地数据与审计

- 私人审核候选：“知识库/私人/审核收件箱/review-*.md”。
- 审核历史：“知识库/私人/审核历史/”。
- 自动运行状态、配置与日志：“知识库/私人/自动收集/”。
- 通过后的正式笔记：“知识库/条目/”，来源在“知识库/来源/”。

私人目录不进入Git、不静态提供、不缓存到PWA。模型上下文只准备已有表达名称/别名、相关候选和审核意见，不提供整库私人笔记、二维码或凭证。只读模型输出经程序校验，人工通过才调用原有写入与回滚逻辑。并发审核用修订摘要拒绝覆盖；重复通过不重复建条目；CLI导入与页面审核共用短时队列锁。

自动读取来源不等于事实已经独立验证。候选标注的是AI采集任务的阅读声明与支持范围，不能冒充源头原帖、统一热度测量或受众测试。无法实际打开原页时不允许把摘要标成已读来源；质量不足可返回空批次。

隔离回归覆盖：新草稿不进主库、意见保留、基于旧版本修订被拒、修订后再次审核、重复通过幂等、跳过/恢复、摘要候选拒绝导入、已有别名去重、运行失败不伪造结果。原有新增、编辑、回收站与HTTP访问控制回归仍保留。
