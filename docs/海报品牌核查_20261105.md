# 三风格生图与品牌工坊核查

2026-11-05：本轮扩展，不覆盖此前阶段记录。

实际使用宿主image_gen.imagegen分别生成反转漫画、萌宠吐槽、复古表情包三张无私人二维码样张。实际发送提示词保存在[样张提示词](../create-funny-meme-cards/assets/poster-studio/samples-prompts.json)，工具未报告具体模型版本，不猜版本号。样张源文件和SHA-256保存在同目录的samples.json；源文件未经二次图像编辑。人工目视：三张标题与副标题可读、风格不同，未发现主文案缺字；漫画样张绿色比默认松绿更亮、额外对话由模型生成，仍待用户审美验收。

已实现：风格切换、提示词编辑与生图任务导出、上传成图、昵称/签名、关键词起名候选、原码上传、网址生成二维码、合成区再次解码核对、PNG与个人配置下载。页面不直接调用模型；修改文字不改变既有样张；未实现配置导入、API直连和自动历史归档。

浏览器实测通过：三张离线样张正常；画布可编码PNG；五个昵称候选点击采用并改变画布；三种风格更新相应提示词；含中文网址生成的二维码与最终合成区解码一致；无效协议被拒绝；未校验的带码导出被阻止；清码正常；上传合成测试码再次识别，PNG编码后再解码仍与原目标一致。测试使用example.com模拟目标，未使用附件中的个人微信码，未检查真实微信平台或目标有效期。

数据/Markdown引用/工坊资源/样张摘要/第三方组件摘要校验、可重复导出检查、skill格式与JavaScript语法检查通过。个人资料仅当前页面内存使用；公共包只包含三张登记过的无私人品牌样张，其他未登记媒体仍由校验阻止。没有创建GitHub远端或发布。

二维码生成依赖qrcode-generator（MIT），解码依赖jsQR（Apache-2.0）；完整许可证与来源摘要随包保留。Context7查询连接失败后使用两项目官方仓库说明与原始源文件核查接口。
